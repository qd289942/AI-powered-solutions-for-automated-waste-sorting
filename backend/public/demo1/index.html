Demo 1 is used to test avaible AI models. You can enter a valid operationSectionId if you want to use this demo in conjuntion with one or more Actuators. The actuators will be informed about the specified trash-label, if detected by the ai. If the operationSectionId is specified the selection of an AI-Model will be overwritten! If you just want to test an AI-Model without an OperationSection you can leave the operationSectionId input empty and select the desired AI Model. If a file is seletected the file will be uploaded to the specified AI-Model, and the results will be displayed on the canvas. The batch size input should be at least 1, and speciefies how many times the image will be uploaded and detected. This can be helpfull to check if the AI is faster in detecting images, that is has already seen.
